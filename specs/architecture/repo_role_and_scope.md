# Repository Role and Scope

## Role

Aeostara is a downstream conformance and execution-spec repository for ASH-based healing behavior.

## Scope In

- Downstream ASH-aligned contracts and algorithms
- Execution interface boundaries for adapters and orchestration
- Acceptance targets proving downstream semantic conformance
- CI gates validating conformance artifacts and schema integrity

## Scope Out

- Upstream ASH semantic changes
- Platform-specific build verification and release operations
- Any framing where Aeostara defines independent semantic truth

## Repository Posture

- Deterministic
- Traceable to ASH sources
- Modular and execution-oriented
- Explicit about legacy vs current authority artifacts
